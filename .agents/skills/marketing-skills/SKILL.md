# Marketing Skills

## Select the workflow

Read `references/CATALOG.md`, find the workflow whose job matches the request, and follow its input, output, and quality requirements. If more than one applies, state the primary workflow and use the others only as supporting steps.

## Operating standard

1. Start with the business goal, audience, offer, channel, deadline, and conversion event. Ask only for missing information that would change the recommendation.
2. Research time-sensitive claims. Cite source URLs and distinguish observed facts from inference. Treat supplied internal documents as the source of truth for the product.
3. Use competitor material to identify patterns: audience, problem, hook, promise, mechanism, proof, offer, objections, CTA, and distribution. Never copy wording, visual identity, scripts, or testimonials.
4. Produce the workflow's required deliverable. Make any unknowns visible as assumptions rather than filling gaps with invented metrics, quotes, or results.
5. End with: recommended next action, owner, deadline or trigger, success metric, and the one biggest risk.

## Safety and publishing

- Do not send outreach, publish content, schedule posts, spend budget, alter a live site, or access private data without explicit approval.
- Never recommend deceptive reviews, fake scarcity, fake testimonials, spam, cloaking, hidden text, or manipulative link schemes.
- Respect website terms, robots controls, rate limits, platform rules, and copyright. Use public data only unless the user provides authorised access.

## Output quality bar

- Be specific enough to implement today.
- Prefer a smaller defensible recommendation over a long unprioritised list.
- Match the requested channel and audience.
- Use tables only when they make comparisons or ownership clearer.
- Reject weak claims and explain what evidence would be needed to support them.
